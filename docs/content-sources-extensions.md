## Local checks

- Targeted ESLint on all five chapters and `bun x --no-install tsc --noEmit`: passed at this integration state.
- Python 3.14.7 on the host ran seven admission-policy tests, seven conversion tests and three synthetic failure-semantics tests: **17 passed**. The container target remains Python 3.13.7; no container build/runtime was executed.
- All five chapter modules loaded through a local raw-text loader. `zsh -n` parsed 31 authored shell blocks without executing them; five JSON patch payloads parsed successfully.
- Bash syntax checked `prepare-tls.sh` and `isolated-recovery.sh` without executing Docker/cluster operations.
- `js-yaml` parsed ten YAML files / 17 documents. Additional offline assertions checked fail-closed/dry-run admission scope, exactly one storage version, and the intentionally tight rollout/quota/PDB arithmetic.
- OpenSSL 4.0.3 executed the local certificate helper in temporary private directories for both service names. Correct SANs passed verification, a wrong hostname failed, Python SSLContext loaded each key/cert pair, and rerunning into a populated directory was refused without replacing the key. Temporary directories and all generated private keys were removed by the test's TemporaryDirectory cleanup.
- No HTTP listener was started. TLS-chain loading and pure function tests do not prove API-server-to-Service connectivity, Pod permission compatibility, admission registration, CRD pruning/defaulting, Docker image availability, etcd recovery execution, or multi-cluster isolation on a real system.
