## Official sources reconsulted

These sources were opened live on the review date for the corrected or potentially ambiguous contracts; existing per-chapter sources remain indexed in [content-sources.md](content-sources.md).

- [Kubernetes 1.35 init containers](https://v1-35.docs.kubernetes.io/docs/concepts/workloads/pods/init-containers/): ordinary init containers do not support startup/readiness/liveness probes, unlike native sidecars. This is the contract behind the corrected sidecar experiment.
- [Kubernetes 1.35 kubectl annotate](https://v1-35.docs.kubernetes.io/docs/reference/kubectl/generated/kubectl_annotate/): replacing an existing annotation requires `--overwrite`.
- [kubectl v0.35.0 wait implementation and examples](https://raw.githubusercontent.com/kubernetes/kubectl/v0.35.0/pkg/cmd/wait/wait.go): `--for=create` is supported in the teaching client family, separately from waiting for a condition.
- [Kubernetes 1.35 Pod lifecycle](https://v1-35.docs.kubernetes.io/docs/concepts/workloads/pods/pod-lifecycle/): omitted Pod `restartPolicy` defaults to `Always`, including after a successful container exit.
- [Helm template CLI reference](https://helm.sh/docs/helm/helm_template/): local rendering evaluates templates, while server-side admission/validity and runtime behavior remain untested.
- [Envoy Gateway 1.9 Helm installation](https://gateway.envoyproxy.io/v1.9/install/install-helm/): controller/CRD installation and their lifecycle need explicit ownership; the exercise must not delete a pre-existing shared namespace as cleanup.

## Limits and learner validation

No Kubernetes API request, cluster creation, controller installation, service/listener, Docker container, port-forward, image build, commit, push or deployment was executed by this review. Real admission/defaulting, image availability, Pod permissions, timing, Service/DNS/CNI behavior, actual Gateway routing and local-path reclamation still require a learner run on the reviewed disposable environment. Expected results remain expectations.

NetworkPolicy enforcement is conditional and cannot be validated on default kindnet. The optional Envoy installation has cluster scope and additional resources. Local kind storage is not CSI or independent backup. A successful syntax/render/unit check does not prove application readiness, physical HA, durable logging or data recovery. These are explicit boundaries of the inspected lessons, not omissions filled with invented execution evidence.
