# Level 3 scaling and availability sources

Consulted 2026-10-22. Teaching baseline: Kubernetes 1.35.0 / kind 0.31.0. These are source checks, not cluster execution evidence.

| Chapter | Official sources | Pinned scope and prerequisites |
| --- | --- | --- |
| hpa | [HPA algorithm and conditions](https://kubernetes.io/docs/concepts/workloads/autoscaling/horizontal-pod-autoscale/), [autoscaling/v2 API](https://kubernetes.io/docs/reference/kubernetes-api/autoscaling/horizontal-pod-autoscaler-v2/), [Metrics Server 0.8.0 requirements and installation](https://github.com/kubernetes-sigs/metrics-server/blob/v0.8.0/README.md), [metrics manifests](https://github.com/kubernetes-sigs/metrics-server/releases/tag/v0.8.0) | Requires working aggregated metrics API and authenticated TLS connectivity to kubelets. The exercise does not silently install it or turn off certificate validation. BusyBox 1.37.0 CPU load bounded by limits. |
| vertical-cluster-scaling | [VPA concepts](https://kubernetes.io/docs/concepts/workloads/autoscaling/vertical-pod-autoscale/), [VPA 1.5.1 source and requirements](https://github.com/kubernetes/autoscaler/blob/vertical-pod-autoscaler-1.5.1/vertical-pod-autoscaler/README.md), [VPA 1.5.1 release](https://github.com/kubernetes/autoscaler/releases/tag/vertical-pod-autoscaler-1.5.1), [node autoscaling](https://kubernetes.io/docs/concepts/cluster-administration/node-autoscaling/) | autoscaling.k8s.io/v1, Off recommendation-only mode; pre-existing VPA and metrics installation. No assumption of optional in-place resize. Provider-based node provisioning is architectural, not demonstrated by fixed-topology kind. |
| pdb | [Disruptions](https://kubernetes.io/docs/concepts/workloads/pods/disruptions/), [configure PDB](https://kubernetes.io/docs/tasks/run-application/configure-pdb/), [policy/v1 API](https://kubernetes.io/docs/reference/kubernetes-api/policy/pod-disruption-budget-v1/) | Eviction API scoped to one exercise Pod; no node drains. Quorum/health and status reconciliations distinguished; direct deletes and Deployment rollouts are not constrained by PDB. |
| ha | [topology spread](https://kubernetes.io/docs/concepts/scheduling-eviction/topology-spread-constraints/), [HA kubeadm topology](https://kubernetes.io/docs/setup/production-environment/tools/kubeadm/ha-topology/), [production environment](https://kubernetes.io/docs/setup/production-environment/), [etcd failure tolerance](https://etcd.io/docs/v3.6/faq/#what-is-failure-tolerance) | Hostname spread with nodeTaintsPolicy: Honor excludes the untolerated control-plane domain; it illustrates logical placement on two local workers only. No physical host/zone failover or production data-replication proof. |

All expected observations remain hypotheses for a separately authorized learner run. The VPA and HPA exercises stop at their preflight if required controllers, CRDs, credentials, certificate configuration or metrics are missing. They do not treat a rendered manifest as evidence of a healthy feedback loop.
