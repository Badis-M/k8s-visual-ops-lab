## Validation evidence

The installed Helm is **4.3.0**, one patch below the lesson's **4.3.1** target. Installed kubectl is **1.37.1** with Kustomize **5.8.1**. Offline client operations do not use or validate a live 1.35 API server. Exact checks and their results are reported to the integrating agent; final application/browser evidence belongs in `docs/content-implementation.md`.

No lab controller was installed, no Kubernetes context changed and no cluster API request or resource mutation was executed. Commands in lessons are learner instructions. Expected sync/health/readiness observations remain unexecuted until the learner runs them in a disposable environment.

The GitOps configuration generator validates inputs locally, writes only the two temporary configuration files in the selected output directory and never retrieves Git objects. A correct SHA syntax is not proof of remote reachability, source trust or a successful reconciliation. Plain Secret YAML/base64 is not encryption; production credential delivery requires separately configured controls.

Completed local checks:

- Targeted ESLint on all four chapter modules and TypeScript at this integration state: passed.
- Prettier on owned TypeScript, non-template YAML/JSON, README and ledger: passed; `Chart.lock` was explicitly formatted with the YAML parser. Raw Go-template manifests were validated after Helm rendering instead of with a plain YAML parser.
- Both charts passed Helm 4.3.0 lint with the optional icon recommendation only. Local dependency rebuild required no remote repository.
- Seven rendered sets (Helm defaults/staging, parent defaults/release-two, Kustomize dev/prod and GitOps app) plus both generated GitOps source configurations parsed as **25 YAML documents**. Assertions checked Service/Pod selectors, generated ConfigMap references, subchart alias naming, replica overrides and changed checksums: passed.
- The four delivery chapter modules imported successfully with the raw fixture loader. All 27 authored Bash blocks passed `bash -n`; quiz indexes were valid with three questions per chapter.
- `replicaCount=0`, credential-bearing/SSH repository URLs and a non-SHA revision were rejected as intended. A non-secret sample HTTPS URL and full synthetic SHA generated configuration offline; no attempt was made to fetch that repository.
- No Kubernetes API request, controller install, remote Git mutation or runtime lab exercise was executed.
